## 0. 前置描述統計(設計輸入,不入判定;in-window)

跑判定前先做五項統計,(b)(c)(d) 的輸出即凍結值來源:

- **(a) MFE 統計**:round 3 陣容各臂(無停利跑法)的最大有利波動(MFE)分佈、
  「MFE − 收盤利潤」讓回幅度分佈——回答「抱到收盤平均讓回多少肉」。
- **(b) 出量殺解剖**:量爆 bar(量 > 前 N 分鐘均量 z 倍 + 創當日新低)的出現率、
  首次出現時間分佈、**殺後至收盤的走勢**(反彈中位數)→ 定 tp1 參數
  (z / lookback / recovery / min_profit),各參數取分佈自然分位,候選 ≤2 組。
- **(c) 墊高結構解剖**:「殺不破前低 + 拉回高點遞增」結構的出現率、
  **確認點 vs 當日最低點的讓肉幅度**、確認後至收盤走勢 → 定新機制參數
  (確認波數 k、比較用 low/close),候選 ≤2 組。讓肉 > 抱到收盤的平均代價
  → 該機制本輪降級觀察(事先聲明,防臨場護短)。
- **(d) 內盤比 UC 分層重驗(前置 gate)**:全池已驗證的「前 15 分鐘累計內盤比
  >55% → 後續摸板率 3~13%」在 **UC 池分層**(tiger 合併 × 開盤高度層)是否仍成立。
  成立 → 內盤比反轉停損照 §2 入對決,反轉門檻 φ 從此統計定值(≤2 候選);
  **FAIL → 內盤比反轉降級觀察,主停損只剩結構前高沿用**(fallback 事先聲明)。
- **(e) 緩漲結束反轉**:僅描述統計(「緩」= 斜率 / 持續 bar 數 / 量能,定義開工寫死),
  觀察不入對決,下輪憑數字升級。
