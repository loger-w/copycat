## 統計項

### (a) 流向反轉解剖(分鐘級近似)

- **攻擊段定義**:連續 N 根 1 分 K 外盤張數 > 內盤張數(N 候選 = 3 / 5,寫死兩檔)
  且段內累計漲幅 ≥ 1%(草稿值;排除無拉抬的橫盤雜訊)。
- **翻轉定義**:攻擊段後首次出現內盤張數 > 外盤張數 × ρ 的 1 分 K
  (ρ 候選 = 1.0 / 1.5,寫死兩檔;連續根數要求 = 1 根 / 2 根,寫死兩檔)。
- **輸出**(base_arm 窗,格式沿 round 4 §0):
  - 出現率、首次翻轉分鐘分佈(p25/50/75/90);
  - **post_move**:翻轉點至收盤走勢(正=續跌;做空的肉);
  - **假訊號率**:翻轉後又創當日新高的比率(被洗的機率);
  - 對照組:round 4 已證偽的「隨機時點內盤比反轉」同表並列——
    驗「加了攻擊段前置條件是否把噪音洗掉」(這是本訊號存在的理由)。
- **GO/DROP 判準(先寫死)**:post_move 中位 > 0 且假訊號率 <
  隨機時點對照組的 2/3 → GO(凍結 N/ρ 取表現自然分位,候選 ≤2 組);
  否則 DROP,想法一出局,(b) tick 回補不啟動。

### (b) 流向反轉 tick 級增量(僅 (a) GO 後跑)

- 同 (a) 定義搬到 tick 級:攻擊段 = 連續外盤成交持續 ≥ T 秒(T 候選 = 60 / 120,
  user 原話「60 秒打個比方」→ 兩檔寫死);翻轉 = 滾動 60 秒窗內盤量 > 外盤量。
- **輸出**:與 (a) 同表 + 兩個增量指標——
  - **提早量**:tick 級翻轉點比分鐘級早幾分鐘(p50);
  - **假訊號率差**:tick 級 vs 分鐘級。
- **GO/DROP 判準(先寫死)**:提早 p50 ≥ 2 分鐘 **或** 假訊號率降 ≥ 1/4
  → tick 版本入 round 5 prereg;否則分鐘級版本就夠,tick 停在觀察
  (回補管道保留,盤中實盤本來就要 tick)。

### (c) 位階對決(CDP / 均線 vs 固定拉幅)

前置檢查兩道,**任一 FAIL 該線出局(事先聲明,user 2026-07-17 已拍板 CDP 條)**:

1. **CDP 線距檢查**:UC 池 T+1 日的 CDP 五值(AH/NH/CDP/NL/AL,由前日 H/L/C 算;
   前日=漲停日,高≈收,線預期擠壓)相對寬度 (AH−AL)/前收 分佈——
   **中位 < 2%(草稿值;約固定拉幅 3.3% 的六成)→ 線擠無鑑別力,CDP 整組出局**。
2. **觸發率檢查**:T+1 盤中高點落在某參考線 ±0.5% 內的比率;
   單線觸發率 < 10%(草稿值)→ 該線出局(均線 MA5/10/20 各自獨立過檢)。

存活線才進對決:

- **對決設計**:回落起點(當日高點)距各參考線的距離分佈,對打
  「開盤價 × (1 + 固定拉幅 3.3~4.1%)」這條隱形線——若高點被固定拉幅解釋得
  更緊(距離分佈更集中),位階指標無增量。
- **增量判準(先寫死)**:控制固定拉幅後,「高點貼近位階線」子集的 post_move
  仍顯著更差(續跌更多)→ GO 入投票;否則 DROP。
  (t1_pull_anatomy 的「拉幅機械固定」結論是本項的既有反方證據,對決要正面回答。)

### (d) 組合形狀(設計原則,非統計項)

- **投票制,不搜權重**(round 1 §3 #3 教訓):存活訊號各給 0~2 分
  (0=反向 / 1=中性 / 2=同向),進場門檻 = 總分 ≥ S,S 候選 = 兩檔寫死,
  變體總數 ≤ 2——「快碰 CDP 但流向+內盤比都強仍可做」由總分自然涵蓋,
  不寫例外規則。
- 連續強度(user 的冷氣溫度比喻)留給**盤中儀表板**(終局=輔助手動下單):
  引擎輸出各子訊號原始強度供顯示,回測只驗離散投票檔位。
