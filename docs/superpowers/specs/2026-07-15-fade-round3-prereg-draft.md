## 2. 停損語意候選(核心變更;最多兩案,參數開工凍結)

**共通鐵律:絕不接受鎖死(2026-07-10 定調 #1)不變。**

- **主案 A+D 組合拳(user 2026-07-15 提案收斂)**:
  - 主停損 = **結構前高 + 緩衝 b**:stop = min(結構高 ×(1+b), 硬線)。
    「結構高」定義按劇本:cell_a = 進場前盤中高點;cell_b = 衝關高點;
    cell_c = 反拉高點;底倉 = T+1 開盤後 running high。
    b 候選 ≤2 值,由「假突破 overshoot 統計」(衝過前高又回落的事件,衝過幅度分佈)
    事先定,cell_b round 2 的 0.005 已證太緊,新值必須 > 該值。
  - 硬線 = **漲 9% 無條件出場**(guard_limit_dist=0.01,距漲停 1%):例行拉抬
    (3.8~4.1%)搆不到、62% 假逼近付費區大幅縮小;開盤時兩線相撞
    (headroom 不足)之事件排除出宇宙並**計數進報告**。
  - 災難停損重錨(取代「虧 4%」):候選二擇一開工凍結——
    (i) 進場後最高價回落式;(ii) 開盤後前 N 分鐘不啟用(N 自高點時間分層 12~15)。
- **次案 B(headroom 比例式)**:guard 距離 = k × 進場 headroom;k ≤2 值;
  與災難停損優先序開工寫死。僅在主案全滅時啟用評估(不同時跑兩案全變體,
  控自由度)。
- **判定輸出強制附「保險精算表」**:停損觸發率 / 每次觸發平均成本 /
  觸發後真鎖板比例(砍對)vs 回落(砍錯)比例——「否」必須自帶機制歸因。
