# UC 池無條件 fade EV 分層(2026-07-14)

回答 round 1 未回答的主問題:「優式(tiger)標的的 fade edge 是否高於一般漲停?」
Round 1 的分層表以 GA top-1 規則 OOS 為量測對象(tiger 每臂 n=1-15,無統計力),
本分析改用**無條件 fade**(T+1 開盤賣、收盤回補)直接對照三池,移除規則選擇自由度。

## 方法

- 樣本:`data/events/events.csv` 全事件(tiger_csv 1,029 / control 2,482 / scan 7,389)。
- 過濾(鏡像 round 1 universe):有 t1_date、日線齊備、gap ∈ [1%, 9.5%)、
  現股當沖先賣資格(BuyAfterSale 'Y'/'＊' 剔除、不在名單剔除、處置期間剔除)。
  過濾後 included = 4,656(gap_band 剔 4,979、不可當沖剔 1,214、無 t1 43、缺日線 8)。
- 指標:oc = (T+1 open − T+1 close) / open(fade 毛報酬);淨 EV = oc − 0.196%(1.6 折成本)。
  T+1 再鎖 = t1 close == limit_up(ref_prev_close),ref = close − spread(缺 spread 以 T 日 close 代)。
- 共同期間:t1_date ≤ 2026-06-26(tiger 標籤截止),排除期間混淆。
- 統計:日聚類 SE(CR0);permutation 以 t1_date 日內分層打散標籤(5,000 次,雙尾);
  成分混淆檢查以「日 × T 日成交額中位數」雙重分層重跑。
- 腳本:session scratchpad `tiger_unconditional_fade.py` / `turnover_check.py`
  (round 2 SC 將正式化為 `fade_diagnose` 子命令後可重現;方法如上完整記錄)。

| 對照 | 差(毛) | p(日內分層 perm) |

Q3 +0.98 / Q4 +0.61;Q1 tiger n=52 樣本薄)。

## 判讀

1. **UC 專屬 edge 首次有統計證據**:淨 +1.19%(2+ 分點 +1.72%)為 scan 池 2-3 倍,
   劑量反應單調(scan < control < 單一分點 < 2+ 分點),p≈0.013-0.025,扛住成交額混淆。
2. **再鎖率低 4pp** 與出貨劇本一致:優式拉完的板隔日更像頂部。
3. gap 組成三池相近(3.9-4.1%),非開盤位置差異。

## 已知限制

1. **期間 = 回測 train 段(in-sample 診斷)**,非 walk-forward;watchlist 來自圈內 intel
   而非報酬擬合,循環性低,但仍需 forward 驗證。
2. **開盤賣→收盤補為無風控紙上數字**(含 20.8% 再鎖事件硬吃約 -5~6%),實戰 guard 會兩頭修剪;
   round 2 需在 1K 粒度 + guard 下重跑本分層。
3. control 為 neigui 依相似性配對之池,tiger vs control 不顯著 → 「分點 intel 超出相似漲停的
   增量」未定案。
4. 多重檢視:3 組對照 + 子群,p 值屬暗示級非定論級。
5. tiger 標籤止於 2026-06-25;持續驗證需分點標籤管道(round 2 前置)。
