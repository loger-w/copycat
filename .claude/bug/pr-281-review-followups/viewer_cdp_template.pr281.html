    CDP 五軸

    用前一交易日的 高 H / 低 L / 收 C:CDP = (H + L + 2C) / 4;AH = CDP + (H − L);NH = 2·CDP − L;NL = 2·CDP − H;AL = CDP − (H − L)。與 copycat 線上 overlay 相同。

    標記(兩張圖一樣,依時間與價位放)

    • 你的成交:紅三角買、綠三角賣(券商交易分時明細 + copycat 成交)。
    • 線上訊號:copycat 當天真的發的訊號;實心紫菱形 = 影子政策列 P / B-a / B-b / S(同檔當日首筆)。
    • 碰觸測試:價格先離某價位 ≥0.8% 再回到 ±1 檔內 = 碰到;朝上三角 = 由上往下碰(當支撐測)、朝下 = 由下往上碰(當壓力測);綠 = 15 分內先反彈 0.5%(守住)、紅 = 先穿過 0.5%、灰 = 盤整。
    • 迴盪後打破:進入某價位 ±0.6% 帶內、停留 ≥10 分、穿越 ≥4 次後第一筆跑出帶外;箭頭 = 方向;紅 = 30 分內先走 +1%(續走)、綠 = 先回 0.5%(反轉)、灰 = 盤整;外圈紫 = 打破那一分鐘量 ≥ 迴盪期均量 4 倍。
    • CDP 突破事件:過 NH / 過 AH / 回測 NH / 跌破 NH / 跌到 CDP / 站回 CDP。
    • 回測交易:空心三角進、叉出、虛線連;紅賺綠賠(每筆 50 萬名目)。

    回測策略(每筆 50 萬名目;進場追 1 檔、出場滑 1 檔;手續費 0.1425% × 2、當日稅 0.15%、留倉稅 0.3%;12:30 後不進;同檔同日一筆)

    活潑日

    當日振幅 =(當日最高 − 當日最低)/ 前收 ≥ 門檻。開「只列活潑日」時左欄只列當天活潑的股票、← → 只在該檔的活潑日之間跳;索引分頁依群組列出全部活潑股票日。

    K 線

    從 1 分 K 現場合併成 1 到 10 分 K。MA5 / MA20 / 布林通道(20 根、2 倍標準差)都用當前週期的 K 棒算,開盤前幾根不足 20 根時不畫。滾輪縮放(以滑鼠位置為中心)、按住拖曳平移、雙擊還原全天;縮放後價格軸依可視 K 棒自動調整,分時圖維持全天。

    操作:← → 逐日換(不跳過);左欄依群組列股票;滑鼠在任一張圖上移動,兩張圖同時出十字線、下方逐筆表跟著捲到那個時間;點圖一下開啟十字線同步與逐筆追蹤(同時固定一條藍色直線在點的時間),再點一下關閉,關閉時拖曳與滾輪縮放 K 線不會被十字線干擾;點逐筆表的一列固定直線。

    • 時間軸:拖曳的是 server 收到時刻(不倒退,比交易所晚約 0.1 秒;前提是本機鐘準)。達錢即時個股成交時刻只到整秒,拿它當軸一秒底下會壓幾十則。
    • 時刻標籤:「成交 hh:mm:ss 之後第 N 則」= 最近一筆成交的達錢時刻(交易所的尺)之後第幾則訊息;成交本身是第 0 則。達錢時刻比收到時刻晚超過 60 秒(例如開機收到前一日盤後成交)或比目前標籤早的成交,不拿來當標籤時刻。
    • 價格階梯:買量 | 價格 | 賣量,高價在上。預設現價上下各 10 檔,現價離開中心超過 5 檔才重新置中;「展開漲停–跌停」列出當日全範圍。現價 = 最近一筆成交價(鎖漲停時買一是價 0 的市價佇列、賣方全空,從五檔推不出現價)。價 0 的市價佇列不畫在階梯上,另列文字。

    • 十字線:拖曳時上方兩張圖的十字線跟著重播時刻與現價走。
    • 播放:速度 1x / 2x / 5x / 10x 以收到時刻計(1x = 真實時間,11:02:00 播到 11:02:50 要 50 秒)。播到最後一則自動停;播放中拖曳時間軸會從新位置接著播;換檔、換日、切到別的分頁會暫停。
    • 逐則步進:「前一則 / 後一則」或鍵盤 ← →(重播分頁開著時 ← → 是逐則步進、不換日,換日用上方 ◀ ▶),會先暫停播放。步進照則號走,同一毫秒收到的幾則也能一則一則看;拖曳時間軸仍取收到時刻 ≤ 該時刻的最後一則。
    • 跳到首次鎖漲停:當日第一筆「成交價 = 漲停價,且成交後賣方沒有限價掛單、買方第一檔是市價排隊或最高限價買 = 漲停價」的成交(與線上鎖漲停訊號同條件;只碰到漲停、賣方還有掛單不算),會先暫停播放。當日沒鎖漲停時按鈕停用。
    • 這一則變了什麼(中間欄):列到目前這一則為止最近 60 則,最新在上、目前這則標亮,往下捲看較早的則。播放時一次重畫常跨過好幾則,跨過的通常也在清單裡;高速播放遇到密集時段,一次可能跨過 60 則以上,要看每一則請暫停後逐則步進。每則以價格跟前一則比,只比兩則都看得到的價位(買方 = 第五檔買價以上、賣方 = 第五檔賣價以下;某側不滿五檔 = 整側看得到):量增加 = 掛單;量減少先扣這個價位的成交,剩下的算撤單。成交則附的五檔常晚幾則才更新(一口氣連吃好幾檔時),所以之後 8 則、1 秒內同價位減少的量仍先算成交;鎖漲跌停時市價排隊減少也先算成交。
